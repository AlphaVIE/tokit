# Security reports

Please report suspected security vulnerabilities through [GitHub private
vulnerability reporting](https://github.com/AlphaVIE/tokit/security/advisories/new).
Include a minimal reproduction, affected version or commit, expected impact,
and any known workaround. Do not post exploit details in a public issue.

If GitHub does not offer the private reporting form for this repository, open
a public issue requesting a private contact method **without including the
vulnerability details**. A maintainer can then arrange a private channel.

Tokit's [security model](spec/SECURITY_MODEL.md) describes the current
language guarantees and their limits. There is no committed response-time or
supported-version policy yet.
