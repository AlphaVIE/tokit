01 / THE IDEABUILT FOR A SHORT FEEDBACK LOOP

A language that gets
to the point.

Small programs should stay small. Tokit keeps syntax concise, gives each program a canonical form, and reports errors in a way a person or an agent can act on.

03 / THE TOOLINGFEEDBACK YOU CAN USE

The compiler tells you what to fix.

Check a file before running it. Diagnostics include a code, location, and concrete message. Use --json to read them from an editor or an agent.

See diagnostic codes →
TERMINALtok check
$ tok check --json shapes.tok
{
  "ok": false,
  "error": {
    "code": "E116",
    "line": 2, "column": 26,
    "message": "non-exhaustive match: missing Some(Square)"
  }
}

04 / GET STARTEDFROM ZERO TO RUNNING

Start with one command.

The installer fetches a release and verifies its SHA-256. Add Rust when you want native builds.

curl -sSf https://raw.githubusercontent.com/AlphaVIE/tokit/main/scripts/install.sh | sh
irm https://raw.githubusercontent.com/AlphaVIE/tokit/main/scripts/install.ps1 | iex
THEN TRY ITtok new hello && cd hellotok run main.tok
