Same function, fewer tokens

Each version returns a typed error for division by zero. Counted with the o200k_base tokenizer used by current OpenAI models.

Across all five executable baselines, the core functions take 182 tokens in Tokit, 226 in Rust, 246 in Python, 273 in Go, 292 in Java, 327 in TypeScript, 342 in C++, and 510 in C. These are small tasks: read the numbers as a direction, and reproduce them with scripts/compare_baseline_tokens.py.

Errors a model can fix in one step

Every diagnostic has a stable code, an exact position, and a message that names the repair. tok check --json returns it as data, so an agent can loop until the program compiles.

  • Exhaustive matching names the missing case.
  • xs.len() is answered with call len(x).
  • Type errors show the expected and the actual type.

What you get

  • One canonical form

    tok fmt and tok compact leave exactly one way to write a program, so generated code diffs cleanly.

  • Safe by construction

    Values instead of references: no null, no unsafe, no data races, no garbage-collector pauses. Overflow stops with a code.

  • Explicit capabilities

    Files, network, and subprocesses need a grant such as --allow-net. tok explain lists every effect before you run anything.

  • Native and WebAssembly

    tok build compiles through LLVM to a single executable, or to a WASI module with --target wasm32-wasip1.

  • Batteries for services

    HTTP and HTTPS, worker-pool servers, TCP, WebSocket, JSON, Redis, PostgreSQL, hashing, files, and parallel tasks.

  • Editor support

    A language server with completion, go-to-definition across files, hover, references, and rename, plus a VS Code extension.

Expressions all the way down

Records, enums with payloads, generics, lambdas, and pattern matching that nests. if and match are values; ? propagates errors; == compares structurally.

The whole language is described in a 2,500-token guide that you can paste into any model's system prompt. Every example in it is compiled and run by the test suite.

Get started

  1. Install

    Run the install command above. Add Rust if you want native builds.

  2. Create a project

    tok new hello && cd hello
tok run main.tok

  3. Hand it to your model

    Paste the guide into the system prompt and let the model call tok check --json. Or fine-tune your own.
